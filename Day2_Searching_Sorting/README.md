# Day 2 - Searching & Sorting

Today I focused on Searching and Sorting algorithms in Java, with an emphasis
on understanding different*Binary Search patterns and applying them to
rotated arrays, boundaries, peaks, and selection problems.

## 🎯 Goals for Today

- Understand standard Binary Search
- Learn Modified Binary Search
- Handle duplicates in Binary Search
- Search in rotated sorted arrays
- Find boundaries using Binary Search
- Find minimum values using Binary Search
- Understand Binary Search based on increasing/decreasing patterns
- Practice sorting & selection
